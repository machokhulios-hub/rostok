# План курса WordPress

1. Проверить текущий блок и официальные источники. Три независимых модуля подготовить в отдельных JSON-файлах, общая схема lesson/theory/ex; основной агент собирает и редактирует содержание.
2. Добавить проверки данных, открытия/сохранения нового курса и экзамена, текстового рендера практики. Увидеть отказ до внедрения. Добавить курс/экзамены, поддержку текстовых примеров в программировании и метаданные маршрута.
3. Создать доступную из курса HTML-памятку: оценка блока, порядок развития, плагины РФ, критерии выбора и сдачи магазина, официальные ссылки. Включить её в офлайн-кеш.
4. Проверить полный npm test, вопросы/уникальность id/источники, неизменность прежних курсов, экзамены и сохранение; независимый обзор. Выпустить следующую свободную версию и проверить GitHub Pages по файлам.

Пользователь прямо поручил создание курса; штатный браузер отключён Work, обход не использовать. Практика на WordPress пользователя и реальная покупка/публикация магазина в задачу не входят.
