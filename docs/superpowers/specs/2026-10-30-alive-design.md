## Суть

Тёмно-синий фон с двумя размытыми цветными пятнами, полупрозрачные «стеклянные» карточки, градиент фиолетовый → голубой на главном действии. Главное отличие от прежних версий — **отклик движением**: число минут набегает, полоса доливается, кольца курсов докручиваются, после урока — крупное «+20» и конфетти, столбики недели вырастают по очереди. Движение всегда отвечает на действие или вход на экран, а не играет само по себе.

## Экраны (телефон до 767 px)

### Главная «Сегодня»
- Заголовок «Сегодня», подпись — день недели.
- Карточка «Выполнено»: крупное число выполненных минут дня, справа «/ N мин» плана, ниже полоса прогресса градиентом. Данные — из текущего снимка дня (личный маршрут 4.35).
- Главная кнопка градиентом во всю ширину: «Продолжить: {следующий шаг}» (из `resumeTarget()` / карточки следующего шага маршрута). Если маршрута нет — «Выбрать цель» (прежнее действие).
- Карточка со списком дел дня: кружок-отметка, название, минуты справа. Выполненное — зачёркнуто, кружок залит `#00D2FF`.
- Сохранить, что уже есть на главной 4.37, но в новом виде: очередь повторения («Повторить N тем», «Слова: N») — строка из двух стеклянных кнопок под главной кнопкой; пять направлений — горизонтальный ряд маленьких колец с подписями под списком дел (переходы те же, что у прежних кругов).

### Курсы («Карта»)
- Список курсов строками: слева кольцо прогресса 44 px (`#00D2FF` по тёмной дорожке), название, «N из M уроков», справа процент.
- Фильтры направлений и поиск 4.21–4.37 сохранить, оформив стеклянными чипами.

### Урок
Макет показывает только экран завершения; сами шаги урока — в тех же токенах:
- теория и примеры — стеклянные карточки, код — прежний тёмный блок с «Копировать»;
- вариант ответа — стеклянная плашка; выбранный — рамка градиентом; верный — `#00D2FF`, неверный — `#FF6B81` и короткое покачивание 200 мс;
- ввод и сборка слов — те же плашки.

### Завершение урока
- Сверху крупное «+N» (реальные XP за урок) градиентом награды, ниже «Урок N пройден», «X из Y верно · Z минут».
- Чипы: серия дней, новые слова (если есть), другое — только из реальных данных.
- Карточка «До звания …»: полоса доливается от старого значения XP к новому, подпись «XP / порог».
- Кнопка градиентом «Дальше: {следующий шаг}» (прежний `nextlesson`), под ней прежние действия (повтор ошибок, к программе курса).
- Конфетти: один залп ~1,2 с, около 40 частиц, CSS или canvas без сторонних библиотек. **Только при первом завершении урока или сдаче экзамена**; при повторе — без конфетти.

## Движение — правила

| Где | Что | Длительность |
|---|---|---|
| Главная, при входе и после отметки дела | число минут считает от прежнего значения к новому; полоса доливается | 600 мс |
| Отметка дела | кружок заливается, вокруг расходится кольцо, всплывает «+N XP» и тает | 400–700 мс |
| Курсы, при входе | кольца докручиваются от 0, с задержкой 40 мс между строками | 500 мс |
| Завершение урока | «+N» появляется с увеличением, полоса XP доливается, конфетти | 300 мс + 800 мс + 1,2 с |
| Неделя, при входе | столбики растут по очереди, задержка 60 мс | 400 мс |
| Неверный ответ | покачивание плашки | 200 мс |

- Анимировать только `transform` и `opacity` (и `stroke-dashoffset` для колец); счётчики — через `requestAnimationFrame`.
- **Не повторять анимации при каждом `render()`**: фоновая синхронизация, смена темы и перерисовка после storage-события показывают итоговое состояние сразу. Анимация — только при переходе на экран или после действия пользователя. Хранить последние показанные значения, чтобы считать «от старого к новому».
- `prefers-reduced-motion: reduce` — всё мгновенно, без конфетти и покачивания.
- Пятна фона не двигаются (экономия батареи).
