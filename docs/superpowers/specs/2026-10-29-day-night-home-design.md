# Росток: дневная и ночная главная
Пользователь выбрал реалистичное дерево из варианта 1, затем согласовал парные дневной и ночной макеты словами «Ставь». Эти макеты — источник оформления.

- Главная: только дерево с пятью рабочими направлениями, небольшой логотип, кнопка солнца/луны, прежняя навигация. Без блоков под деревом.
- Один и тот же пейзаж днём и ночью. Чистые растровые фоны создаются ImageGen из согласованных макетов; все кнопки, подписи и иконки — HTML/SVG.
- По умолчанию автоматический режим по местному времени устройства. Решение реализации: день 07:00–19:59, ночь 20:00–06:59. Состояние обновляется раз в минуту и при возвращении в приложение без пересоздания текущего урока.
- Кнопка справа сверху переключает день/ночь вручную; выбор хранится в существующем rostok-theme (light/dark). Настройки позволяют вернуться в Автоматически. Существующие ручные light/dark сохраняют значение.
- Плавное переключение прозрачности фоновых слоёв; prefers-reduced-motion отключает переход. Управление доступно клавиатуре, названия кнопок отражают действие.
- Телефон: нижняя панель с safe-area, дерево заполняет доступную ширину. Компьютер: прежнее боковое меню и центральная композиция дерева на фоне с согласованными цветами. Без горизонтального переполнения.
- courses.js, постоянные id и дневник прогресса не меняются. Оба фона доступны офлайн. Версия выпуска 4.18, если main не занял её параллельным обновлением.

Рассмотренные подходы: отфильтровывать дневной фон CSS (проще, но нет настоящего ночного неба); два согласованных фона со сменой прозрачности (выбрано для соответствия макетам). Переключение по геолокации не требуется: используются часы устройства.
