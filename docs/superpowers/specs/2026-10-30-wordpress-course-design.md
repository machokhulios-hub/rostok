# WordPress: сайт и магазин с нуля

Прямое поручение пользователя: оценить блок программирования и создать курс WordPress — использование CMS, сайт с нуля, плагины магазина. Уточнена страна: Россия. Курс добавляется в существующий Росток, в Программирование, без установки WordPress на устройство и без реальных платежей.

Основной маршрут: WordPress.org на своём хостинге + блоковая тема/редактор + WooCommerce. WordPress.com объясняется отдельно, тарифные ограничения не фиксируются в учебных ответах. Песочница и тестовая среда предшествуют публикации. Сквозной проект — демонстрационный магазин кроссовок, 12 товаров, размеры/остатки, 5 информационных страниц, оформление, оплата/доставка/почта, восстановление копии.

24 содержательных урока по 3 модулям (по8), 6 вопросов с пояснениями в каждом, 3 экзамена по20 вопросов с порогом80%. Каждый урок содержит объяснение, практику по шагам, самостоятельную задачу, критерии приёмки, диагностику ошибки и запрос к ИИ без секретов. Практический результат проверяется владельцем на своём учебном сайте; выбор ответов в Ростке не выдаётся за автоматическую проверку сайта.

Модуль1: CMS, песочница, установка/хостинг, админка, страницы/медиа, блоки, тема/шаблоны, сборка сайта. Модуль2: WooCommerce, товары/вариации/атрибуты, магазин/checkout, доставка, ЮKassa в тестовом режиме, заказы/возвраты. Модуль3: российские требования как контрольные точки, минимальный набор плагинов, копии/восстановление, почта, SEO, безопасность/скорость, перенос и итоговый запуск.

Выбор плагинов по функции, без установки всего списка: WooCommerce, один проверенный платёжный модуль (ЮKassa как пример РФ); доставка только по задаче; резервное копирование/SMTP/одинSEO по необходимости. Готовые возможности WooCommerce не дублируются расширениями. Проверяются автор, источник, обновления, HPOS и блочный checkout. Юридические/налоговые и маркировочные параметры подтверждает владелец по официальным источникам для своего статуса/товара.

Источники: актуальные WordPress.org/Learn/Playground, WooCommerce, ЮKassa, СДЭК, страницы разработчиков плагинов, ФНС/РКН/Честный ЗНАК. Не фиксировать комиссии, тарифы, номера текущих версий и универсальные ставки налогов. Новый id wordpress, wp-01..wp-24 и wp-x1..wp-x3; прежние курсы/id/прогресс сохраняются.
